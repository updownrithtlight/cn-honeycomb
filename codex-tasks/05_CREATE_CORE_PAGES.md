# 05 创建核心页面

在执行本步骤前，请先完成 `04_CONTENT_DATA_MODEL.md`。

## 目标

创建 `cn.hihoneycomb.com` 的核心页面：首页、产品中心、应用领域、定制能力、关于我们、联系我们。

## 首页 `/`

Title：恒实蜂窝｜金属蜂窝定制厂家
H1：金属蜂窝定制厂家

必须包含：
1. Hero：金属蜂窝定制厂家；提供 EMI/RFI 屏蔽蜂窝通风板、不锈钢蜂窝芯、气流整流蜂窝、风洞蜂窝、蜂窝密封件和屏蔽玻璃等金属蜂窝定制产品。
2. 核心产品：EMI/RFI 屏蔽蜂窝通风板、蜂窝通风波导板、不锈钢蜂窝芯、气流整流蜂窝、风洞蜂窝、蜂窝密封件。
3. 定制能力：材质、孔径、箔厚、蜂窝厚度、外形尺寸、边框、表面处理、按图纸定制。
4. 应用领域：EMI屏蔽、通风散热、风洞测试、流场整流、汽轮机密封、工业降噪。
5. 为什么选择恒实蜂窝：支持定制、聚焦金属蜂窝、可按图纸沟通方案、面向工业工程应用。
6. 询价流程：应用场景、图纸参数、材料结构、报价交期、生产交付。
7. CTA 联系模块。

EMI屏蔽、风洞与流场测试、风机与通风整流、汽轮机/燃气轮机密封、屏蔽视窗、工业降噪。

可定制材料、孔径、箔厚、厚度、形状、边框、表面处理、图纸定制流程、询价参数。

公司简介、产品方向、工艺能力、服务行业、中文站与英文官网说明。不要编造证书和客户案例。

邮箱、地址、英文官网链接、询价说明、客户应提供的参数、静态表单或 mailto。

没有后端时表单不要假提交。
