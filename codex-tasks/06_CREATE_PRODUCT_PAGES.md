# 06 创建产品详情页

在执行本步骤前，请先完成 `05_CREATE_CORE_PAGES.md`。

## 目标

创建主要产品详情页，每个页面要适合中文 SEO，也适合采购和工程师阅读。

## 页面列表

```txt
/emi-shielded-honeycomb-vent/
/waveguide-honeycomb-vent/
/stainless-steel-honeycomb-core/
/copper-honeycomb-core/
/aluminum-honeycomb-core/
/airflow-straightener/
/wind-tunnel-honeycomb/
/honeycomb-seal/
/emi-shielded-glass/
```

## 统一结构

Breadcrumb、H1、产品概述、典型应用、可选材料、工艺方式、可定制参数表、询价需要提供的信息、相关产品、FAQ、CTA。

## SEO 标题建议

- EMI屏蔽蜂窝通风板｜RFI屏蔽通风窗定制
- 蜂窝通风波导板｜屏蔽通风口定制
- 不锈钢蜂窝芯｜304/316金属蜂窝芯定制
- 铜蜂窝芯｜黄铜蜂窝芯定制
- 铝蜂窝芯｜铝合金蜂窝芯定制
- 气流整流蜂窝｜蜂窝整流器定制
- 风洞蜂窝｜风洞流场整流蜂窝定制
- 蜂窝密封件｜汽轮机与燃气轮机密封定制
- EMI屏蔽玻璃｜屏蔽视窗与显示窗口定制

## 参数表字段

材质、孔径/Cell Size、箔厚/Foil Thickness、蜂窝厚度/Depth、外形尺寸、边框结构、表面处理、连接/焊接/钎焊方式、典型应用、是否支持按图纸定制。

## FAQ 要求

每个产品页至少 4 个 FAQ，包括：是否可按图纸定制、询价参数、是否可提供样品、性能如何确认。

## 禁止

不要出现：零售价、市场价、元、No data、undefined、虚假认证、虚假测试数据、虚假客户案例、夸大宣传。

## 输出

输出：创建的产品页、每页 Title/H1、每页 FAQ 数量、相关产品内链、本地访问情况。
