金属蜂窝产品多数属于定制件，不像标准螺丝、轴承那样只靠型号就能报价。供应商要判断材料、工艺、可制造性、损耗、检验和交期，必须知道完整参数。

如果询价只写“我要一块不锈钢蜂窝”或“给我报个蜂窝通风板价格”，通常只能得到粗略范围，甚至无法判断能不能做。更高效的方式是按用途提供关键参数。

## 工程结论先看

金属蜂窝询价至少建议提供这 8 项：

1. 产品用途；
2. 材料牌号；
3. 孔径；
4. 箔厚；
5. 蜂窝厚度/高度/深度；
6. 外形尺寸和图纸；
7. 数量；
8. 检验或测试要求。

如果是 EMI 屏蔽、燃机蜂窝密封、风洞整流或航空航天相关项目，还需要提供频率范围、工作温度、允许压降、装配方式、最终客户标准等信息。

## 为什么同样叫“金属蜂窝”，价格差异很大？

因为金属蜂窝不是单一标准品。影响价格的因素包括：

| 因素 | 对价格和交期的影响 |
|---|---|
| 材料 | 不锈钢、铝、铜、镍基合金成本差异很大 |
| 孔径 | 小孔径加工难度更高 |
| 箔厚 | 影响材料用量、强度和工艺 |
| 蜂窝厚度 | 影响材料、加工时间和压降/屏蔽性能 |
| 外形 | 圆形、异形、环形、带框件加工复杂度不同 |
| 工艺 | 点焊、钎焊、胶粘、压装、外框连接成本不同 |
| 检验 | 普通尺寸检验和第三方测试成本不同 |
| 数量 | 样件和批量价格逻辑不同 |

因此，价格不是由“面积”一个因素决定。面积报价只能作为非常粗略的估算。

## 参数 1：产品用途

用途决定选型逻辑。请先说明产品用在哪里。

常见用途包括：

- 金属蜂窝芯；
- 风洞或风机整流蜂窝；
- EMI/RFI 屏蔽通风板；
- 蜂窝密封；
- 波导窗；
- 吸声蜂窝；
- 结构夹芯；
- 过滤、支撑或防护结构。

用途不同，即使尺寸相同，材料和工艺也可能完全不同。

## 参数 2：材料牌号

请尽量写具体牌号，而不是笼统写“金属”或“不锈钢”。

示例：

- 304 不锈钢；
- 316L 不锈钢；
- 321 不锈钢；
- 310S 不锈钢；
- 铝 3003 / 5052 / 6061；
- 黄铜 H62；
- 紫铜 C1100；
- Inconel 625；
- Hastelloy X。

如果不确定材料，可以提供工况，让供应商协助推荐候选材料，但最终应由设计或客户确认。

## 参数 3：孔径

孔径影响整流、屏蔽、强度、压降、重量和成本。询价时请明确孔径单位和测量方式。

如果图纸没有孔径，可以说明功能目标，例如：

- 用于气流整流；
- 需要低压降；
- 用于 EMI 屏蔽；
- 用于高温蜂窝密封；
- 用于轻量化夹芯结构。

供应商可以给出建议范围，但重要项目仍应由设计确认。

## 参数 4：箔厚

箔厚是金属蜂窝的重要参数。常见写法如 `0.05 mm`、`0.08 mm`、`0.10 mm`、`0.15 mm` 等。

箔厚会影响：

- 蜂窝强度；
- 重量；
- 开孔率；
- 压降；
- 焊接/钎焊工艺；
- 成本；
- 运输和装配变形风险。

如果没有明确箔厚，可以说明强度、重量、压降或成本优先级。

## 参数 5：蜂窝厚度/高度/深度

不同场景叫法不同：

- 整流蜂窝常说厚度或长度；
- EMI 通风板常说深度；
- 蜂窝密封常说高度；
- 结构夹芯常说芯材厚度。

这个参数不能省略，因为它直接影响功能和价格。

## 参数 6：外形尺寸和图纸

最好提供二维图纸或三维模型。至少要提供：

- 长 × 宽 × 厚；
- 直径 × 厚度；
- 内径 × 外径 × 高度；
- 是否有倒角、开孔、法兰、台阶；
- 是否需要外框；
- 公差要求；
- 装配方式。

异形件、环形件、带框件没有图纸很难准确报价。

## 参数 7：数量和交期

样件、几十件、几百件、几千件的价格逻辑不同。数量影响排产、材料损耗、工装、检验和包装方式。

建议同时提供：

- 样件数量；
- 首批数量；
- 年用量；
- 期望交期；
- 是否分批交付。

## 参数 8：检验和测试要求

常见要求包括：

- 尺寸检验；
- 外观检查；
- 材料信息；
- 平面度检查；
- 焊接或钎焊检查；
- 屏蔽效能测试；
- 压降或风量测试；
- 第三方检测；
- 包装和运输要求。

没有明确要求时，供应商一般只能按常规检验执行。特殊测试要提前说明，因为会影响报价和交期。

## FAQ

### 没有图纸能不能报价？

可以粗略估算，但复杂件、异形件、带框件、蜂窝密封和 EMI 通风板最好提供图纸，否则报价误差会比较大。

### 只知道外形尺寸，不知道孔径和箔厚怎么办？

可以先说明用途、风量、温度、屏蔽要求或结构要求，由供应商给建议范围，再由设计确认。

### 为什么样件单价比批量贵很多？

样件需要单独排产、准备材料、调试工艺和检验，很多固定成本无法摊薄，所以单价通常高于批量。

### 面积报价准确吗？

只适合粗估。材料、孔径、箔厚、厚度、外框、工艺和检测要求都会影响价格。

### EMI 屏蔽通风板询价一定要给频率范围吗？

如果有明确屏蔽指标，建议提供频率范围和测试方法。否则很难判断屏蔽结构是否合适。
